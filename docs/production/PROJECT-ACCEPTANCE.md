# 《湿性愈合》项目类型与完成标准

生效：2026-10-25。依据用户四项目验收要求，覆盖旧模板中不适合本作的数量要求，保留原引擎、剧情与存档契约。

## 当前源码识别

- 类型：三章校园视觉小说 / Galgame。
- 架构：React 19 / TypeScript / Vite；PWA + Electron Windows。
- 剧情源：src/story/chapter1.ts、chapter2.ts、chapter3.ts → src/story/index.ts。
- 叙事结构：65 场景、7 次选择、1,296 条路线、4 个最终结局；另有第一章 3 个章节结局与 54 条旧路线迁移。
- 资产结构：public/art/ 36 张图；public/audio/；character-frames 与 full-voice-manifest 管理运行绑定；源文件与制作记录独立归档。

重点验校园人物身份、校服、表情与 CG、事件动作、全文配音和阅读层；校园角色设定独立遵循本作文档。

## 完成门槛

| 维度 | 本作要求 |
| --- | --- |
| 剧情 / 文本 | 主线、开场、推进、高潮与结局完整；合流信息、人物行为与文本口吻一致；无断线、占位或测试正文。结构遍历不代替创作审读。 |
| 美术 | 剧情实际需要的地点、状态、人物 / 信息和关键事件有对应视觉；身份、画风、alpha 与尺寸正确；在实际阅读画面中无严重遮挡或错配。资料页素材不自动计算为正文覆盖。 |
| 音乐 | 标题、日常、情绪、紧张、高潮 / 结局及特殊事件按实际需要配置音乐或有意留白；循环、换曲、后台 / 面板暂停恢复、音量与离线可用。无需每种用途独占一首曲。 |
| 语音 | 被设计为有声的对白 / 证据完整且正确绑定，音色与质量可用，不阻塞阅读；纯文字和旁白不强加无必要的配音。 |
| 音效 | UI、环境与关键动作具有必要音效；与实际动作对应，设置有效，不随重渲染 / 关闭面板重复触发。 |
| 演出 | 按剧情安排文字节奏、停顿、表情 / 信息、场景 / CG 与声音变化；镜头、黑屏、闪白、震屏仅在剧情需要时使用。 |
| 系统 | 新游戏、继续、存读档、历史 / 日志、设置、音量、字速、窗口 / 全屏、标题与异常恢复按平台适用；Web 退出由浏览器承担；调查不强加越过证据和选择的快进。 |
| 分支 | 合法状态遍历覆盖可达内容与结局；选择具有正文、状态、后续或明确意图反馈；隐藏条件合理，无错误跳转、意外循环或不可恢复死路。合流本身不等于伪选择。 |
| 测试 | 原生路线、旧档 / 非法档、真实 UI、资源失败、不同尺寸、真实断网和包体检查；不能用存在 / 解码替代效果和听感。 |
| 发布 | 精确源码对应正式构建；Windows 实际启动 / 存档 / 退出；PWA 实际离线；许可、哈希与下载完整。构建成功不等于 Windows 实际运行，旧版证据不代替本版验收。 |

## 状态规则

✅ 已完成且已验证；🟡 已实现但需完善；🔴 实际需求缺失；⚠️ 已定位 Bug / 质量问题。不适用项明确标明，不冒充缺失。完成度使用可复查的覆盖数，不编造总百分比。

资源完成链：文件存在 → 代码 / 剧情引用 → 游戏实际触发 → 效果正确 → 无明显质量问题。

P0：启动、继续、通关、存档或缺资源崩溃。P1：本作主线、核心玩法、核心视觉 / 声音与关键系统。P2：必要配音质量、事件音效、UI、演出与鉴赏增强。P3：动画细化、便利与整理。既有关键声音证据仍按核心玩法验收。

本轮实际状态见 `ACCEPTANCE-20261025.md`。有剧情范围或实际验证缺口时，不宣称完整作品最终发布质量。
