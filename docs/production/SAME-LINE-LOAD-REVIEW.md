## 问题与修复

`load` 原先只更新游戏状态，而打字重置 effect 依赖场景、段落和正文。当前段落显示完成后，再载入同一位置不会触发该 effect，因此重读、手动读档和 JSON 导入会跳过逐字显示。

在共同的 `load` 入口显式把目标段落的临时字数置零。未确认和取消不调用载入，因此仍保留原显示状态；无需修改引擎、故事或存档 schema。面板关闭、隐藏恢复、速度调整和退出快进继续沿用 v1.0.6 的暂停与保留规则。
