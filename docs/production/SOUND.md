# 完整版声音制作

六首原创音序固定在 `src/game/score.ts`：每首十六拍旋律、四组和弦及独立节拍。`music.ts` 用正弦波和缓慢包络播放，旋律与低音保持克制，不模仿现有歌曲或使用外部录音。

| 曲目 | 场景 |
| --- | --- |
| 九月的雨 | 标题、雨后校园与原第一章 |
| 靠窗的空位 | 邻座、写稿与见夏篇 |
| 一起把纸折好 | 试印、核对与分工 |
| 迟一点的答复 | 家庭沟通与公开范围确认 |
| 黄昏有空 | 休息、江边与放学后 |
| 下一行 | 章节收束与最终结局 |

雨声由确定性四秒噪声循环经低通滤波生成，只有标注雨天的场景开启。翻页与选择用短暂低音量提示；三种声音分别开关、共用音量。首次交互后解锁一个上下文，后台暂停，禁止为每个场景重复创建图或定时器。

音乐鉴赏随实际阅读开启。试听临时启用音乐，不改本地阅读偏好；离开手册恢复原曲与开关。实际浏览器验收测量六首的非零且不削波输出，重复试听仍只有一个上下文，全部声音关闭后上下文暂停。验收位于 `tests/e2e/complete-edition.spec.ts`。

作品交付文字与配乐版，不将系统朗读作为角色配音。素材和生成噪声均在本地运行，断网不改变音景。
