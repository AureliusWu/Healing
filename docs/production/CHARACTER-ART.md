## 表情与运行资源

六种表情固定顺序：平静、微笑、惊讶、担忧、委屈、害羞。害羞保持双眼睁开。各人物生成一个透明 3×2 表情图集；每格都是同一身份、服装、道具与站姿的完整立绘，三视图单独生成，背景不混入图集。

生成工具不一定严格遵守等分格子。`scripts/prepare-art.py --kind atlas` 读取真实主体范围，要求每行恰有三个独立人物，测量六格采样框；格式转换不修改任何像素和 alpha。采样范围存入 `src/game/character-frames.json`，尺寸、边界、哈希与提示词来源存入资源清单。`CharacterSprite` 使用这些范围显示单格，保持同一角色的统一尺寸和头顶边距；不用凭估计的背景偏移裁切手部。

表情写在剧本说话人后，例如 `林见夏[hurt]｜别翻那个。`。解析后标记不出现在玩家文本中。同一角色的表情延续到后续旁白；换说话人时使用对应角色。读档时从本场景台词重建表现，不新增存档字段，不依赖关键词猜测，也不触发新的选择效果。

角色资料页可切换六种表情和三视图；全部资源随 PWA 与 Windows 包离线提供。游戏画面继续使用 v0.1.4 的全窗口背景和下部半透明阅读层。

## 验收

- 一起查看三位角色，核对线条、眼睛、校服结构、发型、手和道具。
- 逐格查看六种表情与透明边缘，再查看真正游戏画面；不得只交付画集而游戏仍显示旧临时素材。
- 验证导入旧存档、重载、旁白保持表情、说话人切换、隐藏界面和短横屏。
- 核对图集、三视图和中文字体全部进入离线缓存。
