# 完整版制作契约

v1.0 收录《生长痛》《显影》《雨停以后》三章与四个最终结局。第一章 v0.1.6 的台词、段落位置、四次选择和三个章节结局保持原样，章末需要明确点击进入下一章。

保存容器仍为 schema 1。`chapter1-v1` 存档只能指向第一章；加载时按选择重建，迁移为 `moist-healing-v1`。新版章节、重读和画廊从真实路线恢复，不能用结局标签伪造前置选择。手动存档、透明度、已解锁回忆保留。

艺术基准仍为 v0.1.4。三位女生继续使用 v0.1.6 的三视图与六表情。新增四个背景、四张事件画面统一为 16:9；提示词、素材尺寸、编码与校验值入库。

六首原创程序配乐，独立音乐、雨声、提示音开关；一次手势后解锁声音。声音不依赖网络。此作品为文字与配乐版，不把浏览器默认朗读当角色配音。

完整路线、旧存档兼容、章节停顿、横屏与竖屏布局、离线资源、Windows 实际 ASAR 启动、线上 PWA 均需验证。发布后才记录正式通过的工作流与预览。
