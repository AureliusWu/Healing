## 四仓交流与依赖

| 提供方 → 接收方 | 采用的方法 | 接收侧需要完成的适配与证据 |
| --- | --- | --- |
| NetLove / Healing / Rain → Circuit | 完整缓存成功才显示离线就绪、安装说明、版本等待与失败恢复 | Circuit 保留 Vite/Workbox 和 Tauri；实现自己的状态适配，验证旧窗口不被新版抢占、缺资源不冒报成功 |
| NetLove → Healing | 完整阅读备份、临时重读返回原位置 | 按 Healing 的三章、1,296 路线与旧章迁移重新验证；保留本作存储键，不能直接接受 NetLove 文件 |
| Rain / Circuit → NetLove | 离线录音制作、稳定台词绑定、重听及自动播放等待语音 | 本作独立音色、独立许可和文本清单；手机用户手势解锁声音，通话/聊天可见性遵循 noSprite |
| Rain → Circuit / NetLove | Prompt、原素材/成品摘要、声音与正文一致性记录 | 新章和新配音按实际新增素材建立来源，不将其他作品录音换名当作本作资产 |
| Circuit → Rain | 按已取得信息浏览、证据原声关联和只读查看原则 | 书签只收藏实际读过的台词，重听绑定原台词/音频；新增字段通过原生持久化与旧档兼容验证 |

共享内容是规则、测试场景、工具配方和具备许可的通用材料。角色、CG、录音身份和存档命名空间分别维护。现有 Rain / NetLove / Healing 制作契约 v1.2.0 及哈希锁定继续有效；本计划将 Circuit 纳入协调范围，共享代码确有变更时再同步其版本、清单和目标侧验证。

## Circuit：v1.5.0《取号》（暂名）

目标：推进《来访》之后的新线索，并补齐玩家可见的 PWA 状态。

- **C1 / 优先**：安装说明、完整离线状态、失败重试、当前版本与检查更新入口；将更新接管改为完整缓存后等待旧窗口关闭。正在调查、推理和重听时保留旧完整版本。
- **C2 / 内容**：第二部第四章，制作预算约 35–45 节点、5 条现场记录、2 轮推理及 2 个可重试错误结局；承接陈伯取号纸在玻璃内侧、空号和最初写卡者的来源核查。至少给出一个可由前文核对的新事实，保留 2019 事故结论和师徒职业分工。
- **C3 / 视听**：按新章需要制作 1 幅场景与 2–3 项场景音效；关键对白最多 8 句，稳定文本后再录制。新素材进入来源清单、字体和完整离线包。
- **完成条件**：v1.4 旧档从《来访》完成位置正常解锁新章；新章各调查门槛、两种错误结局重试及原声重听通过；PWA 新旧两版、多窗口、缺资源、断网重开和四作同源并存通过。Windows NSIS 安装/运行/同档升级/退出卸载及公开三屏另行留证。

## Rain：v1.3.0 已读书签与离线下载反馈

目标：改善完整故事的重访与首次下载体验，沿用 Ren'Py 官方运行时。

- **R1 / 阅读**：在现有历史检索中加入已读台词收藏/取消收藏与按章节筛选；书签保留稳定台词 ID、章节与原声音索引，可在独立列表查看和重听。
- **R2 / 兼容**：新书签使用版本化的原生持久字段，旧档无该字段时初始化为空；只收藏实际已读内容，打开、删除和重听均不推进剧情、不写入任意故事位置。现有 560 台词 ID、16 路线、17 句配音和 v1 存档身份保持。
- **R3 / PWA**：显示完整离线包预计大小及按已验证资源数量/字节计算的下载进度，补明确重试入口；只有完整摘要核对成功才显示可离线，新包等待旧窗口关闭。进度通过安装中 worker 的状态消息适配，不能用下载估算提前写完成。
- **完成条件**：原生 Windows 与官方 WASM 的收藏、删除、章节筛选、原声重听、重启持久化及旧档通过；中文 IME、面板重开和并发查询保持。PWA 下载中断/重试、已缓存旧版继续阅读、新版本等待/激活分别验证；人工试听、计时和重大创作定案保留实际状态。
