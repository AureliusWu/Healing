## 2026-10-07 / v0.1.6 / 原定剧情与统一角色

用户反馈：v0.1.5 的画风偏离，要求按 v0.1.4 规范恢复；撤销玩梗的全员成年约束，回归初始青春期校园剧情，统一角色三视图与表情。

| 实际问题 | 采用的方法 | 可复用位置 |
| --- | --- | --- |
| 许棠的临时 SVG 与两位原角色画法不一致 | 以正式 v0.1.4 的两位角色为画法输入，统一校服、眼睛、发束与赛璐璐阴影；为三人制作三视图和六种表情 | `production/CHARACTER-ART.md`、`prompts/ART-v4.md`、资源清单 |
| 生成器的三列排布未严格等分，直接取格会切到道具或带入邻格像素 | 用内置工具修正边距，再测量实际六个主体，按固定角色尺度与头顶边距采样；只转换编码，保留 alpha | `scripts/prepare-art.py --kind atlas`、`src/game/character-frames.json`、`CharacterSprite` |
| 表情若只记录为临时界面状态，读档与回看会丢失 | 台词明确注解表情，按场景和段落重建；旁白延续对应人物表情 | `src/game/presentation.ts`、表现逻辑和浏览器恢复检查 |
| 成年声明改动了原叙事；追加角色提前用抽象说理回应误会 | 恢复 22 个原场景的可见台词与选择；许棠拥有摄影、月考与家庭期待的实际困扰，误会仍由原雨檐分支推进 | `docs/STORY.md`、`src/story/chapter1.ts` |
| 修改新增场景会影响 v0.1.5 的段落索引 | 保留 `tang-interlude` ID、十六个段落位置与原下一场景；从选择和位置重建当前文本 | 架构、版本说明与逐位置导入检查 |

本地逻辑 20 项与生产构建通过，字体覆盖完整。完整浏览器、预览与双端发布结果以本次 [验证记录](../VALIDATION.md) 为准，执行后补记。

## 2026-10-07 / v0.1.3 / 二维美术与画面优先

用户反馈：阅读 UI 遮挡画面，美术写实感偏高；参考三色绘恋、恋爱绮谭、他人世界末；每次制作保存可复用知识和内容。

| 实际问题 | 采用的方法 | 固化位置 / 后续检查 |
| --- | --- | --- |
| 多块信息卡、正文、选择盖住背景和角色 | 独立场景与底部阅读区；场景信息移到薄页眉，选择和结局收进阅读区 | `src/App.tsx`、`src/styles.css`；横屏边界测试要求场景与 UI 不相交 |
| 背景树叶、反光与人物笔触偏写实 | 保留场景构图与角色身份，明确线稿、平涂和成块阴影规格进行重绘 | `docs/prompts/ART.md`、资源清单；实机人工检查统一画风 |
| 欣赏画面时自动阅读可能悄悄前进 | 隐藏界面停止自动/快进，轻触和键盘只恢复，不推进 | `tests/e2e/reading-layout.spec.ts`；同时覆盖选项处和正常段落 |
| 立绘格式转换可能丢失透明通道或带入不透明底 | 校验真实 alpha、透明角、主体边距，编码后比对 alpha | `scripts/prepare-art.py` |
| 每次新增汉字依靠手动字体处理 | 固定扫描源码、400 字重、WOFF2 和 CJK 字形覆盖检查 | `scripts/subset-font.py` |
| 测试启动会清理临时截图目录 | 完整测试结束后统一生成最终实机预览，避免使用中途被删除或已经过期的截图 | `scripts/live-smoke.mjs`、`docs/previews/` |
| 重载测试夹具在每次导航时覆盖真实存档 | 初始化存档仅在存储不存在时写入，保留重载后真实状态 | `tests/e2e/reading-layout.spec.ts`；断网/重载检查同样遵守 |

素材生成经验：包含较长负面约束的第一轮角色提示被内置工具误判，具体触发原因未确认。改用清楚的日常校服、人物特征、姿势、线条与透明规格后成功。透明边缘再使用同一工具清理，最终在真实背景上核对；验收脚本同时记录完整 alpha 边界与主体边界，避免将极淡的边缘像素当成裁切。最终采用的提示词与实际结果记录在素材文档。

完成结果：本地与云端 16 项逻辑、28 项浏览器用例通过。Windows 源码与实际 ASAR 启动通过；线上电脑、手机横屏、手机竖屏的离线重开、画面分区与隐藏界面通过。v0.1.3 双端已公开，代码提交 `02b0975a2be970fdd9dd432f8372a9fe69eb0e57`。完整流程网址、截图与下载证据见 [验证记录](../VALIDATION.md)。
