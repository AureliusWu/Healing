# v0.1.0 · 第一章可玩基线

> 历史基线版本。该版本曾作为仓库中的实际 `package.json` 版本与 README 标注版本存在，但当时没有建立正式 GitHub tag / Release。本文件依据当时仓库内容补录，不把它伪装成正式发布记录。

第一章《生长痛》在这一版本已经形成完整可玩基线：玩家扮演程屿，在江城七中的九月校园中与林见夏、陈知遥相遇。

- 完整第一章，包含 4 次关键选择、54 种选择组合与 3 种章节结局。
- 两位主要角色立绘与两张校园背景已经接入游戏。
- 支持逐字文本、自动阅读、快进、已读回看与结局回忆。
- 支持自动存档、3 个手动存档位，以及 JSON 导入/导出，可在手机与电脑之间迁移进度。
- Web/PWA 与 Windows Electron 桌面端共用同一套游戏内容和存档数据结构。
- PWA 首次缓存完整资源后可离线重开；Windows 版资源随安装包/便携包提供。
- 已包含响应式横竖屏布局、键盘操作、减少动态效果选项与原创 Web Audio 轻音乐。
- 无账号、无 API 密钥、无运行时外部请求。

当时的验证覆盖全部 54 条路线、存档恢复、场景可达性、非法存档拒绝、手机/电脑浏览器交互以及 Windows 桌面启动与打包后启动检查。

后续 v0.1.1 明确保持了 v0.1.0 存档兼容。
