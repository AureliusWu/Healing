# v1.0.1 · 发布信息对齐

《湿性愈合》三章完结版的维护更新。v1.0.0 的下载元数据仍写成第一章剧情标识，发布脚本的标题也固定为“生长痛”；本次将发布信息与实际游戏、版本说明对齐。

- 发布元数据从经 Windows 源码和实际 ASAR 包验证的路线夹具读取当前剧情标识与存档容器版本，并由逻辑检查确认夹具能在当前引擎重放。
- 当前剧情标识为 moist-healing-v1，存档容器仍为 schema 1；下载元数据同时列出 chapter1-v1 和 moist-healing-v1 的兼容性。
- GitHub Release 标题使用本版本更新日志的标题；版本不匹配的标题、缺失的构建 ID、相互矛盾的实机夹具会阻止发布。
- 增加九项真实发布脚本的回归检查：生成 JSON、逐行文件校验值、标题、五项上传、已发布版本不可覆盖、草稿重试、外来标签/草稿拒绝和上传摘要失败不公开。检查在独立受控网络中运行，并进入正式 CI。

三章剧情、统一角色美术和玩家进度沿用 v1.0.0。PWA 与 Windows 使用同一版本；现有自动存档、手动存档和 JSON 导入继续兼容。旧版本的标签和下载保留，新版通过新构建发布。

本地发布回归与剧情检查、正式双端构建、Windows 实际包启动及线上三屏幕离线复验结果记录在 [验证记录](../VALIDATION.md)。
