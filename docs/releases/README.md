## 固定发布规则

1. `package.json` 的版本号只要发生变化，同一个提交中必须新增或更新 `docs/releases/vX.Y.Z.md`。
2. 每份日志至少说明：主要新增/变化、兼容性或迁移影响、桌面端与 PWA 状态、验证/测试结果。
3. 本索引必须加入新版本链接；不允许只有 GitHub Release 文案而仓库内没有永久日志。
4. CI 发布阶段会运行 `scripts/check-release-notes.mjs`。当前版本缺日志、日志未进入索引或索引存在未覆盖的版本文件时，正式发布直接失败。
5. 仅修正文档且不升版本时，不新增版本日志。

根目录的 [`CHANGELOG.md`](../../CHANGELOG.md) 只作为入口，本目录及各版本 Markdown 文件是版本历史的长期记录源。
