# 湿性愈合 v0.1.2 · 横过来，让故事铺开

第一章《生长痛》现在以横屏作为主要游玩方式。

- PWA 安装后优先横屏；手机网页竖屏显示可关闭的旋转提示。
- 标题页、阅读界面和设置都提供全屏入口。支持的触屏浏览器在全屏后尝试锁定横屏；可随时退出。
- 优化手机短横屏的标题、立绘、底部对话框、剧情选项与菜单。考虑屏幕安全区域，选项与正文不会相互遮挡。
- 横竖屏切换与全屏不会丢失阅读位置，旧版本存档继续兼容。竖屏仍可阅读。
- Windows 安装版、便携版和 PWA 同步更新。

若画面没有旋转，请开启系统自动旋转并横向握持手机。部分浏览器需要手动旋转。

已安装的 PWA 可在“安装与离线”中检查更新。新版本完整下载后，关闭所有游戏窗口再打开即可使用，存档会保留。

下载中的 `release.json` 记录本版本源码提交与构建结果，`SHA256SUMS.txt` 提供文件校验值。
