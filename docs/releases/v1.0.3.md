# v1.0.3 · 双端离线边界与复用素材

《湿性愈合》三章完结版的可靠性修订。维持现有角色、场景、剧情与存档格式，修复同一网站下多份安装的离线状态与缓存边界，补齐 Windows 实际程序和发布重试的验收。

- PWA 缓存版本同时计算相对路径、文件长度和实际字节；资源改名同样会产生更新。缓存按完整注册 scope 隔离，激活只清理本部署的旧缓存，保留无法确定所属部署的历史缓存。
- 离线就绪只由本游戏注册的 worker 完成激活确认；同源父目录 worker 的全局 ready 不再提前宣布三章资源可离线使用。更新继续等所有游戏窗口关闭，阅读和选择保持原位置。
- Pages 产物名称包含运行编号与重试编号，避免部署重试后多个同名产物阻止发布。Windows 启动验收使用不抢焦点、静音、全屏退出后隐藏的真实 Electron 窗口，继续验证全屏、完整画面、底部阅读层、旧章续读、CG 和结局；原生全屏转换仍可能瞬时显示。
- 共享制作契约与素材索引记录用途、来源、许可、摘要和复用边界。原始美术未随仓库提供的项目明确标注，角色与剧情 CG 保持本项目专用；界面能力和制作工具可按契约复用。
- 现有发布回归修复 Windows Node 预加载文件 URL 兼容；新增 PWA 注册生命周期、摘要和缓存隔离测试。三次冷/热启动与阅读交互测量保存在本地测试产物中。

继续兼容 schema 1、game `moist-healing`、旧 `chapter1-v1` 与完整 `moist-healing-v1`。两端数据仍通过 JSON 导出/导入迁移。PWA 下载更新后关闭所有游戏窗口再重开；Windows 使用新安装包或便携程序。

本地检查、实际 Windows 程序、PWA 离线与升级、CI 及公网结果分别记录在 [验证记录](../VALIDATION.md)。系统安装对话框与真实安装器升级的结果单独标明，不以接口桩或 ASAR 启动代替。
