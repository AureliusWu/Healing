# v0.1.3 · 把画面还给故事

阅读界面改为独立画面与底部文本区。场景信息放进薄页眉，选择与章节结束提示收进阅读区，背景和角色不再被常驻 UI 覆盖。横屏画框保持 16:9 完整背景，短屏选择区支持滚动。

新增「隐藏界面」与 `H` 快捷键。欣赏画面时暂停自动与快进；轻触画面、恢复按钮、`H` 或 `Esc` 回到当前段落，不会误推进或代选。

重新绘制校园、教室与两位角色，采用更明确的二维轮廓、平涂与赛璐璐阴影，延续原有角色特征和校服。参考国 G 官方画面的视觉组织，游戏素材仍为原创制作。

新增制作规范、迭代记录、最终提示词和资源清单；固定每次制作保存可复用内容的仓库约定，并提供透明素材转换与中文字体子集脚本。

PWA 与 Windows 共用此次更新，兼容原有存档、全部第一章路线和结局。发布流程验证两端与线上离线阅读后提供安装版、便携版和 PWA 包。
