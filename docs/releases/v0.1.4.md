# v0.1.4 · 让画面真正铺满

游戏阅读界面改为全窗口画面：背景与角色直接铺满整个游戏窗口，不再保留顶部信息栏和独立 16:9 画框，让场景成为整个桌面与横屏设备的底层视觉。

对话框、剧情选择与功能键合并为底部一体化半透明浮层。返回标题、全屏、设置、存档、回看、自动、快进与隐藏界面都集中在同一区域，减少对画面的长期占用。

新增阅读层透明度调节，默认 72%，可在约 35%–95% 范围内调整；对话区和功能键同步变化，并持久保存用户设置。隐藏界面、自动/快进、存档与原有快捷键行为保持兼容。

本次没有修改剧情路线、角色设定、第一章内容或存档 schema。Web/PWA 与 Windows 桌面端共用同一套实现。

发布前验证覆盖 16 项剧情与存档逻辑测试、28 项浏览器实测、生产构建、Windows 源码启动、Windows x64 安装版/便携版打包与打包后启动检查。PWA 在正式部署后继续执行线上与离线重开复验。
