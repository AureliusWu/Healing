# v0.1.6 · 回到十七岁的秋天

本次按 v0.1.4 的美术与初始剧情方向修正 v0.1.5 的偏差。

- 撤销全员成年约束与关于页面的对应声明，恢复高二、十七岁秋天的设定。保留女生生日、身高和体重资料，年龄与高中年级协调。
- 恢复月考压力、家庭期待、表达困难、朋友边界与初次心动的主线。许棠的插入场景改为《没寄出的样张》，围绕摄影被当成分心与家长会压力展开；她有自己的困扰，矛盾仍由原有雨檐分支推进。
- 三位女生统一沿用 v0.1.4 的二维线稿、赛璐璐上色与米白 / 墨绿校服；移除许棠临时 SVG，提供三组三视图、每人六种表情，共十八个表情立绘。
- 台词带明确表情标记，表情在旁白中延续、随说话人变化，并能在读档时恢复。角色资料页可浏览六种表情及三视图。
- 保留全窗口画面、半透明一体化对话与操作层、透明度设置及手机页面内沉浸模式。

## 兼容性

存档 schema 1、`chapter1-v1`、原四次选择、54 种组合与三种结局保持不变。原有场景段落数量与选择 ID 保持不变；v0.1.5 的 `tang-interlude` 仍保留同一 ID 和十六个段落位置，读取后对应本次修订文本。历史文字和表现从选择与剧情位置重建；无需重开，也不导入旧存档中的年龄声明或表情状态。

## PWA 与 Windows

双端使用同一份剧本、人物图集与三视图。新增资源由生产构建进入完整原子离线缓存。已有公开版本保留；v0.1.6 的安装版、便携版与 PWA 下载由完整验证流水线生成。

## 验证
