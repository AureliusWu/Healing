# v1.1.0 · 阅读备份与临时重读

完整阅读备份携带自动存档、三个手动槽位、三章章首、已读结局、插图与音乐回忆，并保留实际路线证明。导入前显示内容摘要，取消不写入；只更新文件中存在的位置，合并回忆记录，存储空间不足时回滚本次改动。旧单份存档和第一章存档仍可导入，原单份导出入口保留。

已读记录新增“临时重读”，可重新选择，再返回原路线和未完成的文字位置。临时重读保留原自动进度与回忆解锁；另存手动槽位或沿此路线继续均需明确确认。

历史版本若只留下解锁标记而没有对应路线，完整备份会提示先读取相关存档补齐证明；原数据及单份导出继续可用，不会静默删除回忆。普通本地阅读时会保存紧凑路线证明，换掉四个槽位后仍可迁移已读插图。

本地 71 项逻辑（含 1296 完整路线、54 旧版路线）、9 项发行协议、素材校验、字体覆盖和生产构建通过。浏览器回归汇总 75 通过、3 项设备限定跳过，含新增 6 项双端备份与临时重读检查；一次报告文件冲突的既有用例已独立重跑通过。Windows 与公开部署以本提交后精确版本证据为准。
